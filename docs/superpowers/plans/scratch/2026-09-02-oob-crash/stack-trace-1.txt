Crash type: WebAssembly.RuntimeError: "function signature mismatch"
(an indirect call (call_indirect) through the wasm function table hit
a table slot whose actual signature didn't match the expected one at
the call site) -- NOT literally "memory access out of bounds", though
plausibly a different symptom of the same underlying corruption this
investigation is chasing (see docs/superpowers/notes/2026-09-02-oob-crash-findings.md for discussion).
