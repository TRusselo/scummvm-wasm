# EmulatorJS Divergence Branch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Maintain our EmulatorJS changes as a branch that exports back to
`patches/*.patch`, then use it to bump the pin to just below upstream's
frontend split.

**Architecture:** A long-lived branch on `TRusselo/EmulatorJS`, one commit per
logical change, based on the upstream pin. An export script writes each commit
to the patch file `assemble.sh` already consumes, so the build input never
changes shape. Bumps become `git rebase` plus `git cherry`, not hand re-cuts.

**Tech Stack:** git, bash, GNU patch, Node (syntax checks only).

**Spec:** `docs/superpowers/specs/2026-09-19-emulatorjs-divergence-branch-design.md`

## Global Constraints

- Current pin: `EJS_COMMIT="0b1c5e9"` at `build/emulatorjs/assemble.sh:33`.
- Target pin for step 2: `13ce942`, the commit immediately below the frontend
  split `f4f0f1c`.
- `ARG EMULATORJS_COMMIT=0b1c5e9` at `/home/user/git/romm/docker/Dockerfile:170`

- Branch commit order MUST equal `assemble.sh` apply order: 01, 02, 03b, 04,

- Patch file numbers keep their gaps after drops. Do not renumber.
- Commit trailers on this repo: `Assisted-by: Claude:claude-opus-5`. Never
  `Co-Authored-By: Claude`.
- Step 3 (the frontend split) is OUT OF SCOPE. It gets its own plan once the

### Task 3: Export script, and switch assemble.sh to -p1

One task, not two: exported patches carry diff headers, so `assemble.sh` must
use `-p1` for them to apply. Landing these separately leaves the build broken
in between.

**Files:**
- Create: `build/emulatorjs/export-patches.sh`
- Modify: `build/emulatorjs/assemble.sh` (the patch-application block, lines
  126-145 as of `240e30b`)

**Interfaces:**
- Consumes: branch `scummvm-wasm` and its `Patch-File:` trailers from Task 2.
- Produces: regenerated `patches/*.patch` with diff headers, and an
  `assemble.sh` that applies every patch with `patch -p1 -d "$WORK/ejs"`.

- [ ] **Step 1: Write the export script**

```bash
cat > /home/user/git/scummvm-wasm/build/emulatorjs/export-patches.sh <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")/../.."

# Writes each commit of the divergence branch to the patch file assemble.sh
# consumes. The branch is the source of truth; patches/ is generated.
#
# Output filename comes from the commit's Patch-File: trailer rather than a
# slug of the subject, so a reworded commit message cannot silently rename a
# patch that assemble.sh references by name.

BRANCH="${1:-scummvm-wasm}"
BASE="${2:-}"
WORKTREE="${EJS_WORKTREE:-/tmp/ejs-branch}"
OUT="build/emulatorjs/patches"

[ -d "$WORKTREE" ] || { echo "error: no worktree at $WORKTREE" >&2; exit 2; }
if [ -z "$BASE" ]; then
  BASE="$(grep -oP 'EJS_COMMIT="\K[^"]+' build/emulatorjs/assemble.sh)"
fi
echo "==> exporting $BASE..$BRANCH from $WORKTREE"

count=0
for sha in $(git -C "$WORKTREE" rev-list --reverse "$BASE..$BRANCH"); do
  name="$(git -C "$WORKTREE" show -s --format='%(trailers:key=Patch-File,valueonly)' "$sha" | tr -d '[:space:]')"
  if [ -z "$name" ]; then
    echo "error: commit $sha has no Patch-File: trailer" >&2
    exit 1
  fi
  git -C "$WORKTREE" diff "$sha^" "$sha" > "$OUT/$name"
  echo "    $name"
  count=$((count + 1))
done
echo "==> wrote $count patch(es) to $OUT/"
EOF
chmod +x /home/user/git/scummvm-wasm/build/emulatorjs/export-patches.sh
```

Expected: `==> wrote 10 patch(es)`, listing the ten filenames.

```bash

# Generated by export-patches.sh from the scummvm-wasm branch, so every patch
# carries diff headers and applies uniformly. Order matters: 09 before 08, as
# both rewrite the quick save/load block and 08 adds the severity argument to
# the messages 09 leaves behind.
for pf in 01-cache-streaming 02-emulator-onfile 03b-canvas-pointer-supports-mouse \\
          04-savestate-retry 05-download-debug-logging 06-parse-core-report \\
          09-loadstate-retry 08-message-severity \\
          10-quickload-host-event 11-english-variant-no-langjson; do
  patch -p1 -d "$WORK/ejs" < "build/emulatorjs/patches/${pf}.patch"
done
'''
open(p, 'w', encoding='utf8').write(s[:start] + new + s[end:])
print("rewrote the patch block")
PY
bash -n build/emulatorjs/assemble.sh && echo "assemble.sh parses"
```
